# AIお弁当盛り付けロボット（3D・6マス版）

## 作品概要

MuJoCo上のSCARAロボットと3本爪を用いた、
AIお弁当盛り付けシミュレーションです。

RGB-Dカメラから食品の中心位置と大きさを推定し、
CNNで食品を分類して、6区画へ盛り付けます。

普通サイズの食品を優先し、特大・余剰・注文外の
食品は回収します。

## お弁当の注文

| 第1区画 | 第2区画 | 第3区画 |
|---|---|---|
| おにぎり | 卵焼き | ブロッコリー |
| 唐揚げ | おにぎり | 卵焼き |

下段は第4～第6区画です。

## 主な技術

- CNNによる5種類の食品分類
- RGB-D画像による食品中心座標の検出
- RGB-D画像による相対サイズ推定
- 複数画像のCNN推論による分類安定化
- 注文内容に基づく6区画の配置計画
- 3本爪SCARAロボットの逆運動学制御
- 従来方式・CNNのみ・提案AI・理想識別の比較
- 日本語音声付き120秒動画の生成

## 実測評価

保存されたsummary.jsonに基づく結果です。

| 方法 | 食品取扱成功率 |
|---|---:|
| 従来固定順 | 33.3% |
| CNNのみ（サイズ判定なし） | 55.6% |
| 提案AI | 94.4% |
| 理想識別（真値使用） | 100.0% |

提案AIの規格外品回収率：
100.0%

評価シーン数：4

詳細な実測結果は results/summary.json を参照してください。

## Google Colabでの再現方法

1. Bento6_Reproduce_Colab.ipynb を開く
2. GPU（T4 / L4 / A100）を設定
3. セルを上から実行
4. CNN学習・MuJoCo評価を実行
5. 120秒MP4とPDFを確認する

## ファイル構成

- scene_3d.py：6マス弁当と3本爪ロボット
- vision_model.py：CNN、RGB-D、中心位置検出
- run_project.py：学習・推論・配置計画・評価
- make_video.py：120秒動画・日本語ナレーション
- make_report.py：日本語PDF生成
- test_*.py：動作確認用テスト
- results/：実測結果、画像、動画、PDF

## 技術的な制約

食品位置の認識は既知の供給セル配置を利用します。
3本爪は開閉しますが、食品の保持は簡易拘束です。
配置後の評価ではMuJoCoの真値を利用しています。
実機ロボットでの動作は未検証です。
